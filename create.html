Create an RGB contract or invoice

Issue a token or make an invoice, for either RGB line, on a Bitcoin test network. It runs offline in your browser with each line's own code: nothing is sent anywhere, and no keys are involved.

Test networks only. Early development, not for real funds. Each result depends on a secret generated here. Save it: without it you can't prove or spend what the seal holds.
Nothing is broadcast. The outpoint only has to exist on chain when the asset is used.
Made with rgbjs: each RGB line's own Rust code compiled to WebAssembly, v0.11 (rgb-protocol 0.11.1) and v0.12 (RGB-WG 0.12.0-rc.3). Check any file you make here.
